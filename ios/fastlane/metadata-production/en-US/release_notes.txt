What's new in 0.2.0

- Windows remotes: connect to Windows OpenSSH hosts and switch windows with MonkeyMux over ConPTY, with agent-session discovery and shell completion.
- Cursor Agent CLI joins the launch presets alongside Claude Code, Copilot CLI, Codex, Gemini CLI, OpenCode, and Antigravity.
- In-app browser to preview forwarded ports without leaving the app.
- Sharper terminal rendering, including inline Kitty graphics and images.
- Smoother on-screen keyboard handling and terminal input fixes.
