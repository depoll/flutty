Test the latest MonkeySSH agent workflows on iPhone or iPad. MonkeySSH beta puts native agent conversations, a full SSH terminal, MonkeyMux or tmux windows, and SFTP in one remote workspace.

Choose the right view for each task:

- Open supported agents in a native window with readable chat, streamed tool progress, permission controls, images, attachments, session history, and a mobile composer.
- Switch to the full terminal whenever you need direct CLI control, xterm-256color, inline images, gestures, modifier keys, function keys, macros, or IME-friendly typing.
- Keep agent and shell work running in persistent MonkeyMux windows. Reconnect, switch windows, and share the same session with your desktop.
- Find recent project-scoped sessions and save launch presets for Claude Code, Copilot CLI, Codex, OpenCode, Antigravity, Cursor Agent, Pi, Hermes, OpenClaw, and Grok Build.
- Browse, upload, download, create, and edit remote files over SFTP.
- Generate or import Ed25519 and RSA keys, verify host keys, use jump hosts, and cancel slow connection attempts.
- Forward remote ports, manage live tunnels, and open forwarded services in the in-app browser.
- Save snippets, macros, home-screen shortcuts, and per-host startup settings for repeat work.

Your hosts, keys, snippets, and settings stay on your device. PIN and biometric lock are available, and MonkeySSH does not require cloud sync. Optional analytics and crash reports are off by default and exclude commands, terminal output, paths, hostnames, usernames, clipboard contents, and credentials.

One connected native chat, SSH, terminal, SFTP, and the choice between native and terminal agent windows are available without Pro.

This beta listing receives preview and internal testing builds before the public MonkeySSH app.
