What's new in this 0.3.1 beta

- Terminal Enter now matches the physical keyboard, including toolbar modifiers and Alt+Enter.
- TUI box borders stay locked to the monospace grid instead of drifting off-cell.
- MonkeyMux theme focus defaults are simpler and no longer special-case agent names.
- Cursor Agent and Copilot CLI theme refresh fixes on window focus and Windows hosts.
- Terminal height shrinks no longer wipe rows below the cursor or drop image rows.
- Stability fixes across keyboard input, MonkeyMux window titles, and agent window switching.

Thanks for testing the beta — please report anything that feels off.
